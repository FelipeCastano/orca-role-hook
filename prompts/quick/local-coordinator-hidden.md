# Local coordinator: hidden roles
Read on demand from local-coordinator.md (same folder), which names the moment to read it. Everything in local-coordinator.md still applies.

## Hidden roles
A hidden role has no tab and no Orca task. To give it a task, write the brief to a file in your scratchDir, as self-contained as any brief, and run `~/.orca-roles/bin/hidden-role.sh <id> --brief <file> --tag <a tag of yours, unique in this worktree>` from the worktree without asking the user, then end your turn. Its result arrives as a `status` "Hidden role done": read the report file it names, as you would a `worker_done`; `outcome=failed` is a failed task, and `marker=missing` means the report does not start with `Done`: the run may have skipped its role's prompt, so do not accept it as it is. Read the report, tell the user in one line, as the "Report marker" rule in local-coordinator.md says, and recommend running it again with its prompt sent afresh: the same brief, a new tag and no `--resume`, so the role's files and hidden-worker.md's text are sent again in full. Run it again on their yes; do nothing else to the role. A `status` "Hidden role question" carries a question in its report's last line: answer it with `hidden-role.sh <id> --brief <file with the answer> --tag <new tag> --resume <session>`. Each run starts with no memory otherwise, a hidden role is never compacted or cleaned, and where a step names a task id you give the tag. In team-status, a hidden role with a run in flight shows `hidden-running`. To interrupt it: `hidden-role.sh --stop <id>`. After a restart, or if a result does not arrive, run `hidden-role.sh --status`: `running` is a run in flight; `undelivered` is a result that never reached you, so read its report file (a tag listed both as `undelivered` and as `lost` is `undelivered`: read its report); `lost` is a run that ended with no report, so treat it as a failed task and look at what it left in the worktree. Once handled, `hidden-role.sh --ack <tag>` stops listing it. A run in flight is not stopped by a mode or phase switch: stop it first if it no longer applies.
